# Руководство пользователя Food Delivery v2.0

## 1. Введение
Food Delivery v2.0 — это консольное приложение для оформления заказов еды, накопления бонусов и просмотра истории покупок.
Для запуска приложения убедитесь, что установлен Python 3, и выполните команду в терминале:
```bash
python app.py
```

## 2. Быстрый старт
1. Запустите приложение через терминал.
2. В появившемся меню выберите нужные позиции каталога.
3. Перейдите к подтверждению, примените промокод (при наличии) и оформите заказ.

## 3. Основные функции

### 3.1. Меню и корзина
1. Просмотрите список доступных блюд и напитков.
2. Добавьте выбранные позиции в корзину.
3. Для получения скидки 10% введите промокод `SAVE10`.
![Меню приложения](docs/screenshots/menu.png)

### 3.2. История заказов
1. Выберите в меню пункт просмотра истории заказов.
2. На экране отобразится список завершенных заказов с датами и суммами.
3. При выборе конкретного заказа открывается его подробный состав.
![История заказов](docs/screenshots/history.png)

### 3.3. Программа лояльности
1. При совершении каждого заказа начисляется 10% бонусов от итоговой суммы (например, 100 бонусов при чеке в 1000 рублей).
2. Накопленные баллы сохраняются на вашем балансе.
3. Бонусы можно списать для скидки при оформлении следующего заказа.
![Баланс бонусов](docs/screenshots/bonus.png)

## 4. FAQ
- **В: Где физически хранятся оформленные заказы?**
  О: Все данные записываются локально в файл `orders.json`.
- **В: Где сохраняется бонусный баланс?**
  О: Баланс фиксируется в файле `bonus.json`.
- **В: Что делать, если не работает промокод `SAVE10`?**
  О: Убедитесь, что промокод введен заглавными буквами латиницы без лишних пробелов.
